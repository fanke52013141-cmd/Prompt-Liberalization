# 提示词优化实验室 · 单机版 v0.1 使用说明

这是一个装在你自己电脑上的小工具：把你在用的提示词贴进来，用几个真实例子看清它哪里不行，改好一版给你对比，你觉得靠谱再转正。所有数据都存在本机，不经过任何第三方服务器。

## 第一次使用（约 5 分钟）

1. **装 Python**（只装这一次）：去 [python.org/downloads](https://www.python.org/downloads/) 下载安装。安装第一屏务必勾选 **“Add python.exe to PATH”**。已经装过 Python 3.8 以上的可跳过。
2. **双击 `启动.bat`**：会弹出一个黑窗口（这是程序本体，别关），然后自动打开浏览器进入操作页面。
3. **点「设置」**：填三项——
   - 接口地址（例如 `https://api.openai.com/v1`，或你所用平台的地址，一般以 `/v1` 结尾）
   - API 密钥（只存在你自己的电脑上）
   - 模型名（填你开通的模型）
   
   点「测试连接」，提示正常就可以开始了。

## 日常怎么用（三件事）

| 你想干什么 | 去哪里 | 会发生什么 |
|---|---|---|
| 改进一条提示词 | 新建优化 | 贴提示词＋2—8 个真实例子 → 看现在的输出并指出问题 → AI 改一版 → 左右打乱盲评 → 存为试用版（未考试） |
| 日常干活 | 用一用 | 贴今天的输入直接出结果；用完点一下“直接用了 / 改了改 / 没用上”，输入自动存进例子池 |
| 试用版转正 | 考个试 | 用攒的**新例子**（建议 20 份以上）把正式版和试用版放一起盲评，通过才转正；随时可回滚 |

## 花多少钱

- 每轮优化有**次数上限**（默认 40 次），到顶自动停，已完成的部分都保留。设置里可改，也可以切换成“按金额”模式（需填单价）。
- 「花费与记录」页能查每一笔调用，包括失败的那几次。
- 一轮小探索通常 3—9 次调用、几毛到几块钱；一次考试约为例子数 × 2 次。

## 认清三件标记

- **正式版**：考过试转正的，日常默认用它。
- **试用版（未考试）**：看起来更好但还没验证，日常可以手动切换着用，页面会一直标着“未考试”。
- **结论“只能当参考”**：例子少于一定数量时，系统会如实说“还看不出来”，不会骗你“提升明显”。

## 常见问题

- **黑窗口关了会怎样？** 程序就停了。再双击 `启动.bat` 就回来，数据都在。
- **测试连接报“密钥不对”？** 重新复制密钥；注意别多复制了空格。
- **报“接口地址没找到（404）”？** 检查地址结尾，一般要以 `/v1` 结尾。
- **数据在哪？能不能删？** 全在软件目录的 `data/lab.db` 一个文件里，删掉它就等于恢复出厂。
- **能让别人通过网络访问吗？** 不能，程序只监听本机（127.0.0.1），这是有意的安全设计。

## 已知边界（如实说）

- 单用户设计，没有登录密码——因为它只允许你自己这台电脑访问。
- 例子太少时考试无法给出“确实更好”的结论，这不是故障，是诚实。
- 「按金额」上限依赖你填的单价，单价不准时金额只是估算。
